# trøtt.no

**Bør du sove litt nå? JA.**

En liten og unødvendig nettside med et veldig tydelig svar og en unnskyldning for å ta en dupp.

## Besøk siden

**[trøtt.no](https://trøtt.no)**

Siden er publisert via GitHub Pages.

## Hva gjør den?

- Svarer «JA.» på spørsmålet om du bør sove litt nå.
- Viser kommentarer tilpasset ukedagen og klokkeslettet ditt.
- Gir deg en ny unnskyldning når du trykker på knappen.
- Gjemmer noen små påskeegg ved utvalgte klokkeslett.

## Om prosjektet

Dette repoet inneholder kildekoden og tekstene til trøtt.no. Nettsiden er laget med HTML, CSS og JavaScript, med et enkelt oppsett tilpasset mobil og større skjermer.

Målet er å holde siden liten, rask og akkurat passe unødvendig. 

Sidne er ment som humor, ikke som søvnråd.
